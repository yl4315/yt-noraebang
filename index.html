                            내 Drive의 'YT 노래방' 폴더에 MR과 곡 목록(가사·가사 시각·사용자·재생목록), 기기마다 점수·부른 횟수 파일(stats-…json)을 저장해요. 폴더의 stats 파일은 지우지 마세요 (지우면 그 기기 기록이 다른 기기에서 안 보여요). 이 폴더에 MR 파일을 직접 넣어도 다음 동기화 때 곡 목록에 들어와요. 앱이 만들지 않은 파일은 읽기만 해요. 녹음은 위를 켜면 함께 올라가요. 로그인은 한 시간쯤 유지돼서, 그 뒤에는 Drive 버튼을 한 번 눌러 주면 돼요.

                            클라이언트 ID 설정 (보통은 안 바꿔도 돼요)
                            클라이언트 ID 만드는 방법
                            1. Google Cloud 콘솔에서 새 프로젝트를 만들어요 (이름 예: YT 노래방).
                            2. API 및 서비스 → 라이브러리에서 Google Drive API를 찾아 사용을 눌러요.
                            3. OAuth 동의 화면(또는 Google 인증 플랫폼)에서 앱 이름·이메일을 넣고, 대상은 외부, 테스트 사용자에 내 Gmail을 추가해요.
                            4. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기, 유형은 웹 애플리케이션.
                            5. 승인된 JavaScript 원본에 http://localhost:5173과 휴대폰·노트북에서 여는 주소 https://yl4315.github.io를 넣어요.
                            6. 만들어진 클라이언트 ID를 복사해 위 칸에 붙여넣고 저장 → Google 계정 연결.
                            7. "확인되지 않은 앱" 안내가 나오면 내가 만든 테스트용 앱이라 그런 거예요. 계속을 누르면 돼요.

# 예태 노래방 (YT 노래방)

**바로 열기: https://yl4315.github.io/yt-noraebang/**

집에서 쓰는 노래방 웹앱이에요 (앱 이름 "예태 노래방", 폰 홈 화면 이름 "노래방"). MR을 넣고 가사에 맞춰 부르고, 녹음하고, 점수를 받고, TV 화면에 띄워서 예약까지 할 수 있어요.

## 켜기

1. **`YT 노래방 켜기.bat`** 을 더블클릭해요. 검은 창이 뜨고 브라우저가 열려요.
2. 검은 창을 닫으면 꺼져요.
3. 처음 켤 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러요. 휴대폰 리모컨에 필요해요.

**TV로 바로 노래하려면 `YT 노래방 TV로 켜기.bat`** 을 더블클릭해요. 크롬이 주소창 없는 창으로 열리고, 바로 TV 화면(대기 화면)이 나와요.

- 크롬이 꺼져 있었으면 처음부터 전체 화면으로 열려요. 크롬이 이미 켜져 있었으면 창으로 열릴 수 있어요. 그때는 화면에 나오는 안내대로 **아무 키나 한 번 누르면**(또는 `F`) 전체 화면이 돼요.
- 곡과 녹음은 평소 쓰던 크롬 안에 있어서 그대로 보여요. 크롬이 없으면 기본 브라우저로 열려요.
- 노래방이 이미 켜져 있으면 서버를 또 켜지 않고 TV 화면만 열어요. `T`를 누르면 TV 화면에서 나가서 관리 화면이 돼요.

직접 켤 때는 이렇게 해요.

```
python server.py            # 이 PC에서만
python server.py --lan      # 같은 와이파이의 휴대폰 리모컨도 허용
python server.py --open     # 켜면서 브라우저 열기
python server.py --tv       # 켜면서 크롬을 TV 화면·전체 화면으로 열기
```

마이크는 https 주소(위의 **바로 열기** 주소)나 이 PC의 `http://localhost:5173` 에서 돼요. 브라우저가 그 밖의 주소(예: 같은 와이파이 주소 `http://192.168…`)에서는 마이크를 막아서, 서버로 켤 때는 노래방 화면을 이 PC에서 여세요. 주소 끝에 `?tv=1`을 붙이면(예: `http://localhost:5173/?tv=1`) 열자마자 TV 화면이 돼요.

## 주요 기능

| 기능 | 어디서 |
|---|---|
| 곡 추가 (MR·동영상 + 가사) | 곡 목록 → `+ 곡 추가` |
| 여러 곡 한 번에 넣기 (가사 자동) | 곡 추가 창에서 MR을 **여러 개** 고르기 (폰은 파일을 길게 눌러 여러 개, PC는 곡 목록에 끌어다 놓아도 돼요). 파일 이름에서 제목·가수를 채우고 가사를 차례로 찾아요. 확실한 것(싱크 + 제목·가수 같음 + MR 길이 3초 안)은 저절로 넣고, 애매한 곡만 골라요 |
| 내 노래 파일에서 MR 만들기 | 곡 목록 → `내 노래 파일에서 MR 만들기` → 새 탭 "MR 만들기 창"(집 AI 서버)에서 노래 파일 고르기 → 목소리를 뺀 MR이 저절로 "여러 곡 한 번에 넣기" 창에 들어와요 → `저장`. 집 밖에서는 Tailscale을 켜 주세요. 창이 노래방과 안 이어지면 창의 `MR 받기`로 저장해서 `+ 곡 추가`로 넣어요. 서버 주소는 처음 한 번 `설정` → `더 보기 (고급)` → MR 만들기에 넣어요 (주소가 없으면 단추가 안내와 `주소 넣기`를 보여 줘요). 허브에 로그인해 있으면 허브에도 넣어서 내 다른 기기도 같이 써요 |
| 유튜브 곡 (유튜브 노래방 영상으로 부르기) | 검색 창(`S`) → `유튜브 노래방 검색` 탭(Tab), 또는 곡 목록 → `유튜브 곡 넣기`. 링크 붙여넣기 · 폰 유튜브 앱 `[공유]` → 노래방 · 검색 열쇠가 있으면 제목으로 검색. 아래 "유튜브 곡" |
| 가사 없는 곡 한꺼번에 찾기 | 곡 목록 위 `가사 없음 N곡 · 찾기` (Drive 폴더로 들여온 곡도) |
| 시각 붙은 가사 자동 찾기 | 곡 추가 창 → `제목·가수로 가사 찾기` (안 나오면 영어 제목으로) |
| 가사 시각 직접 맞추기 | `가사 맞추기 ›` → `가사 맞추기` (Space로 찍기, ⌫ 되돌리기, 1~4 배속) |
| 가사 전체 당기기·미루기 | `가사 맞추기 ›` → `가사 타이밍` ±0.1초 / ±1초, `[` `]` |
| 키 바꾸기 | `키 ♭/♯` 또는 `,` `.` (사용자별로 곡마다 기억해요) |
| 녹음 · 녹음 후 싱크 조절 · 녹음 나누기 | ● 버튼, 내 녹음 → `싱크·믹스 조절`, WAV 저장. 폰은 `공유`(작은 파일로 카톡 등에 바로), PC는 `작은 파일 저장` |
| TV 화면 · 예약 | `TV 화면` 또는 `T`. 번호 + Enter 예약(또는 조작 막대 `번호` → 화면 숫자판), `P` 우선예약, `S` 검색(초성 가능), `L` 예약 목록, `C` 인기차트, `M` 내 목록, `J` 간주점프, Esc 취소 |
| 폰을 TV에 이어 부르기 | 폰으로 TV 화면을 열고 선이나 화면 복제로 TV에 띄우기 (아래 "폰을 TV에 이어서 노래방으로") |
| 사용자 · 좋아요 · 재생목록 | 위쪽 사용자 버튼(`U`), 곡의 ♡ / ＋, `내 목록` 탭 |
| 휴대폰 리모컨 | TV 대기 화면의 QR 코드를 휴대폰으로 찍기 (같은 와이파이) |
| 내 폰 리모컨 (허브) | `설정` → `더 보기 (고급)` → **내 폰 리모컨 (허브)** → `폰 리모컨 받기` 켜기 (허브에 로그인해 있을 때만 보여요). 켜 둔 동안 TV 대기 화면에 이 리모컨 QR이 나와요 (기본 길). 같은 노래방 주소에서 허브에 로그인한 폰으로 `리모컨`(`remote.html`)을 열면 휴대폰 리모컨과 같은 화면으로 조작해요. 와이파이가 달라도 되고 `server.py`가 없어도 돼요 (아래 "내 폰 리모컨") |
| 손님 QR (같이 있는 사람이 폰으로 예약) | `설정` → **손님** (설정 창 맨 위) → 손님 초대 QR (또는 TV 대기 화면의 `손님 QR 켜기`). 손님은 폰 카메라로 찍으면 로그인 없이 곡 찾기·예약·내 예약 빼기·지금 곡 보기·키(−2~+2)를 해요. 와이파이가 달라도 돼요 (허브 연결 필요). 손님 폰에는 아무것도 남지 않아요. 다 놀면 `방 닫기` (아래 "손님 QR") |
| Google Drive 동기화 · 녹음 백업 | `설정` → Google Drive 곡 창고. 켤 때 맨 위 **"Drive와 맞추기"** 띠를 한 번 누르면 로그인과 맞추기가 같이 돼요 |
| 기기 맞추기 (점수·부른 횟수) | 맞출 때마다 기기마다 점수·부른 횟수가 Drive로 가고, 인기차트·최고 점수·오늘 최고 점수에 **모든 기기 합계**가 보여요 |
| 여행 준비 (폰에 곡 다 받기) | `설정` → `더 보기 (고급)` → 맨 위 **여행 준비** → 로그인·맞추기 → 남은 공간 확인 → 많이 부른 곡부터 받기 → 영구 저장. 멈춰도 다시 누르면 이어서 받아요 |
| 인터넷 없이 부르기 | 기기에 저장된 곡은 오프라인에서도 돼요. `설정` → `이 기기에 저장된 곡` (한 줄 요약, 누르면 펴짐) |
| 백업 파일 | `설정` → `더 보기 (고급)` → 백업 파일 만들기 / 불러오기 (`.ytbackup`) |
| 허브 연결 (곡 설정 맞추기) | `설정` → 곡 창고의 `이 기기에 저장된 곡` 바로 아래 **허브 연결**: 허브 코드를 붙여 넣고(또는 `#hub=nbhub1.…` 주소로 열고) 메일·비밀번호로 로그인. 그다음부터 곡의 가사(시각 포함)·가사 타이밍·기본 키를 고치면 3초 뒤 허브에 저장되고, 다른 기기에 **같은 MR 파일**을 넣으면 그 설정이 저절로 들어와요. 인터넷이 없을 때 고친 것은 모아 두었다가 돌아오면 보내요. 허브 코드를 안 넣으면 지금처럼 이 기기·Drive만 써요 |
| 자동 맞추기 | 시각 없는 가사 곡의 무대 아래 `자동 맞추기` 단추 (`가사 맞추기 ›` 줄 바로 아래, 고급을 꺼도 보여요). LRCLIB에 **곡 제목·가수·길이만** 보내 시각 붙은 가사를 찾아 넣어요. 진행 막대 아래 한 줄에 찾음 / 불러옴 / 못 찾음 `직접 맞추기`. 자동으로 넣은 곡은 `자동 맞춤 · 확인해 주세요` 단추로 `가사 맞추기`를 열어 확인해요 |
| 집 AI 가사 시각 (MR 만들 때 같이) | 집 AI 서버가 가사 시각 맞추기를 할 수 있으면, MR 만들기 창이 곡마다 가사를 물어요 → 노래방에 같은 곡이 있으면 그 가사, 없으면 LRCLIB(제목·가수·길이만)에서 찾은 시각 없는 가사로 **MR을 만들며 시각도 같이 맞춰요**. 여러 곡 넣기 창에 `✔ 집 AI 시각 · 확인해 주세요`로 들어오고, 시각이 많이 틀릴 수 있는 곡은 후보로만 보여요. 시각을 못 맞춰도 MR은 그대로 들어와요 |
| 원곡 파일로 자동 맞추기 | 시각 없는 가사 곡의 무대(아래 조작부 `자동 맞추기` 줄, 또는 곡 수정 창) `원곡 파일로 자동 맞추기` → MR 만들기 창에서 **목소리가 있는 원곡 파일**을 고르면 집 AI가 가사에 시각을 붙여 돌려줘요. 기다리는 동안 한 줄에 "집 AI가 맞추는 중" + `그만두기`. 시각이 많이 틀릴 수 있거나 이미 시각이 있는 가사면 넣기 전에 물어요 (처음 고른 답 = 넣지 않기). 넣지 않은 결과는 그 곡의 수정 창을 열면 가사 후보 "집 AI"로 한 번 더 볼 수 있어요 (이 화면에서만, 새로 고치면 사라져요). 목소리가 없는 파일이면 `다른 파일로`, 서버 주소가 없으면 `주소 넣기`. 집 밖이면 "집 AI에 닿지 않아요 · 집에 가면 다시 해요" |
| 복잡한 설정 보기 | 기본 화면은 자주 쓰는 칸만 보여요. 음향 세부(에코·리버브·멜로디 가이드·녹음 싱크)는 `음향 설정` → `더 보기 ›`, 그 밖에 숨긴 칸은 `설정` → **`더 보기 (고급)`**을 켜면 예전처럼 다 보여요 (이 기기에서 기억). 단축키는 그대로예요 |

## 유튜브 곡

- 내 MR 대신 **유튜브 노래방 영상**으로 불러요. 영상은 유튜브 공식 플레이어(IFrame)로 **보이는 채로만** 틀어요: 광고·로고·유튜브 단추를 가리지 않고, 영상 칸은 200×200보다 작아지지 않아요. 화면이 숨으면 멈춰요.
- 넣는 길 셋: ① 유튜브 탭에 링크 붙여넣기 (youtu.be/… · watch?v= · shorts/) → `[예약하기]` ② 폰 유튜브 앱 `[공유]` → 노래방 (노래방을 홈 화면에 설치했을 때) ③ 검색 열쇠가 있을 때만 제목으로 검색 (검색어 뒤에 "노래방"). 열쇠가 없으면 `[유튜브에서 열어 찾기]`로 유튜브에서 찾아 `[공유]`해요.
- 검색 열쇠(YouTube Data API)는 허브가 `ytSetKey()`로 **메모리에만** 넣어요 (저장소·화면·기록에 쓰지 않음). 하루 한도가 차면 링크·`[공유]` 길로 돌아가요.
- **재생목록 한꺼번에 넣기**: 유튜브 탭에 재생목록 링크(`youtube.com/playlist?list=…`, 또는 목록 안 영상 링크)를 붙이거나 폰 유튜브 앱에서 재생목록을 `[공유]` → 노래방 하면 미리 보기 카드 "재생목록 N곡"이 나와요 → `[곡 목록에 다 넣기]`. 곡 목록에만 넣고 **예약은 안 해요** (곡 목록에서 골라 예약). 곡 목록에 있는 곡은 건너뛰고, 한 번에 앞 200곡까지 넣어요.
  - 검색 열쇠가 있으면 제목을 미리 보고, 노래방에서 안 틀어지는 곡은 "M곡은 노래방에서 안 틀어져요 (유튜브 앱에서는 돼요)"로 알려 주고 빼요 (`[그 곡도 넣기]`를 켜면 같이 넣어요). 지웠거나 비공개인 곡은 빼요.
  - 열쇠가 없으면 유튜브 플레이어에 목록을 잠깐 올려(틀지 않음) 영상 번호만 읽어요. 제목은 틀 때 보여요.
  - 내 목록(나중에 볼 동영상·좋아요 표시한 동영상)과 유튜브가 자동으로 만든 믹스는 넣을 수 없어요.
- 검색 열쇠로 찾으면 **금영 공식 채널 영상이 먼저** 나와요 (순서만 바꿈, TJ 영상은 그대로 나와요).
- 유튜브 곡은 **키 바꾸기·녹음·반주 볼륨이 꺼져요** (단추는 흐리게 + 한 줄 안내). **점수는 마이크로 그대로** 받아요. 영상 소리를 빼거나 녹음·내려받기하지 않아요.
- 가사: 영상 길이를 알면 LRCLIB 시각 붙은 가사를 확실할 때만 자동으로 넣어요. 싱크 편집기도 돼요 (2배속까지).
- 재생 못 하는 영상(퍼가기 막힘·지워짐)은 안내 + `[유튜브에서 열기]`, 예약곡이 있으면 3초 뒤 다음 곡. 폰이 자동 시작을 막으면 "▶ 눌러서 시작".
- 예약곡이 차례로 이어지다가 인터넷이 끊기거나 느려서 유튜브 곡을 못 틀면 "못 틀어서 건너뛰어요"를 보여 주고 3초 뒤 다음 예약곡으로 넘어가요 (예약 목록이 멈춰 서지 않아요). 손으로 고른 곡은 안내만 해요. 유튜브 플레이어가 15초 안에 준비되지 않으면 그 플레이어는 버리고 다음에 새로 만들어요.
- 노래방에서 안 틀어지는 영상(퍼가기 막힘·지워짐·비공개)은 곡에 기억해서 곡 목록·예약 목록·리모컨·손님 화면에 "노래방에서 안 틀어짐"이 붙어요. 예약 차례가 오면 틀지 않고 바로 다음 곡으로 넘어가요 (손님이 예약한 곡이면 그 손님 폰에 "OO 곡은 노래방에서 안 틀어져서 넘어갔어요"). 곡은 지우지 않아요. 곡을 눌러서 고르면 한 번 더 틀어 보고, 틀어지면 표시가 없어져요. 이 표시는 이 기기에만 있어요 (Drive·백업 파일에는 안 가요).
- 퍼가기를 막은 영상(유튜브 오류 101·150, 예: 노래방 회사가 막은 영상)은 큰 `[유튜브 앱으로 열기]` + "유튜브에서 부르면 녹음·점수·예약곡 이어 부르기는 안 돼요". 이 단추를 누르면 3초 뒤 다음 곡은 멈춰요 (예약 목록은 그대로). TV 화면에서는 링크 대신 "TV 유튜브 앱에서 이 곡 찾기" + 찾을 말(제목 가수 노래방) + 폰으로 찍는 영상 QR.
- `설정` → `더 보기 (고급)` → **유튜브 곡** → `프리미엄 계정으로 틀기 (이 기기만)`: 켜면 이 기기에서만 유튜브 로그인 정보(쿠키)를 쓰는 플레이어(www.youtube.com)로 틀어요. 기본은 꺼짐(로그인 정보를 안 쓰는 youtube-nocookie). 백업 파일·Drive·허브·손님 폰에는 안 가요. 광고를 막거나 건너뛰지 않아요 — 프리미엄 계정에서 광고가 없어지는지는 유튜브가 정해요 (광고가 계속 나오면 다시 꺼 주세요). 퍼가기를 막은 영상은 켜도 노래방에서 안 나와요.
- TV 화면: 영상은 위 칸, 아래 68 띠에 `[곡 검색 S]` `[예약 목록 L]` `[일시정지 Space]` `[⏭ 다음 곡 N]` `[나가기 T]`. 창을 열면 영상이 옆으로 비켜요. 안 되는 키 안내와 아래 알림은 띠 안에 3초.
- 폰: 멈춰 있는 유튜브 곡은 곡 검색·예약 목록 같은 창을 열면 영상이 잠깐 숨어요 (창이 무대를 다 씀). 재생 중이면 위 영상 · 아래 창으로 나누고 무대가 창만큼 길어져요.
- Drive를 쓰면 유튜브 곡은 **곡 정보(영상 번호·제목·가사)만** 곡 목록 파일에 올라가요 (영상 파일은 없음). 허브에 곡 설정을 남기는 것은 CR-227.

## 데이터는 어디에 저장되나요?

- 곡, 가사, 녹음은 **이 브라우저 안 저장소(IndexedDB)** 에 있어요. 이 폴더에는 없어요.
- 다른 브라우저나 기기에서는 보이지 않아요. Drive에 연결하거나 백업 파일로 옮기세요.
- 녹음은 `설정` → Google Drive 곡 창고 → `녹음도 Drive에 백업하기`를 켜야 Drive에 올라가요 (기본 꺼짐). 꺼져 있으면 녹음을 저장할 때 "이 기기에만 있어요 · 백업 켜기: 설정 › 곡 창고"가 같이 나오고, 녹음 목록의 그 녹음 줄에 `백업 안 됨` 표가 붙어요. 표를 누르면 백업 켜는 칸으로 바로 가요 (저절로 켜지지는 않아요).
- 이 저장소(GitHub)에는 코드와 데모곡만 올라가요. MR, 가사, 녹음은 올라가지 않아요.
- 허브에 연결하면 곡의 **가사(시각 포함)·가사 타이밍·기본 키만** 허브에 올라가요. MR·동영상 소리 파일은 올리지 않아요 (곡 열쇠는 MR 파일 내용으로 만든 지문이라 같은 파일이면 같은 곡). 허브 연결 정보(주소·공개 키·로그인)는 이 기기(`nb-hub…`)에만 있고 백업 파일·Drive에는 들어가지 않아요. `연결 끊기`를 두 번 누르면 이 기기에서 지워져요 (곡·가사는 그대로).
- MR 만들기는 고른 노래 파일을 **집 AI 서버**(Tailscale 안에서만 열림)에 올려 목소리를 빼요. 서버는 곡을 쌓아 두지 않아요 (올린 곡은 끝나면 바로, 만든 MR은 받은 5분 뒤 지움). 노래방은 서버에 직접 요청하지 않고, MR 만들기 창이 다 만든 파일을 노래방 창에 넘겨 줘요.
- 가사 시각 맞추기(MR 만들 때 같이 · 원곡 파일로 자동 맞추기)는 고른 소리 파일과 **가사 글**만 집 AI 서버로 가요 (곡 이름은 파일 이름으로만). 서버 기록에는 가사·곡 이름을 남기지 않아요.

## Google Drive 연결

클라이언트 ID는 앱에 들어 있어요(`js/cloud.js`의 `DEFAULT_CLIENT_ID`, Google Cloud 프로젝트 `yt-noraebang`). `설정` → **Google 계정 연결**만 누르면 돼요.

- 로그인할 수 있는 계정은 Google Cloud의 **테스트 사용자**에 넣은 계정뿐이에요. 가족 계정을 쓰려면 그 주소도 테스트 사용자에 넣으세요.
- Drive의 **'YT 노래방' 폴더에 MR 파일을 직접 넣어도** 다음 동기화 때 곡 목록에 들어와요. 파일 이름에서 제목·가수를 자동으로 뽑아요. 가사는 곡 목록 위 `가사 없음 N곡 · 찾기`로 한꺼번에 넣어요.
- 폴더에는 기기마다 **`stats-<기기 id>.json`**(그 기기의 점수 기록·부른 횟수)이 생겨요. 기기는 자기 파일만 쓰고 남의 파일은 읽기만 해서 두 기기가 동시에 맞춰도 부딪히지 않아요. 지우면 그 기기 기록이 다른 기기에서 안 보여요.
- 켤 때 로그인 창을 저절로 띄울 수는 없어요(브라우저가 막아요). 그래서 맨 위 띠를 한 번 누르게 했어요. 로그인 정보는 기기에 저장하지 않아요 (새로 열면 다시 눌러요).
- 클라이언트 ID의 **승인된 JavaScript 원본**에는 `http://localhost:5173`과 `https://yl4315.github.io`가 들어 있어야 해요. 다른 주소에서 열면 로그인이 막혀요.

## 휴대폰에서 쓰기

**https://yl4315.github.io/yt-noraebang/** 를 휴대폰 크롬이나 사파리에서 열고, **홈 화면에 추가**하면 앱처럼 설치돼요.

- 휴대폰 리모컨(QR·코드)은 이 PC의 `YT 노래방 켜기`(또는 `TV로 켜기`)로 연 화면에서만 돼요. GitHub Pages 주소에서는 **내 폰 리모컨 (허브)** 을 써요 (아래).

### 폰을 TV에 이어서 노래방으로

PC 없이 폰(또는 노트북) 하나가 노래방이 되고, TV는 화면만 보여 줘요. 어느 TV든 돼요.

1. 폰을 TV에 이어요. USB-C→HDMI 선(충전 단자 있는 것이 좋아요) 또는 TV의 화면 복제(Smart View 등).
2. 앱을 열고 `TV 화면`을 눌러요. 설치한 앱 아이콘을 **길게 누르면 `TV 화면으로`** 가 바로 있어요.
3. 화면을 한 번 누르면 전체 화면이 되고 폰이 가로로 고정돼요. 가로가 안 되면 폰을 직접 돌려요.
4. 아래 큰 버튼으로 다 해요: **`번호`** 를 누르면 숫자판이 나와서 곡 번호로 예약해요. `곡 검색`, `예약 목록`, 시작·일시정지·취소·간주점프. 키·반주 볼륨·녹음·마이크는 **`⋯ 더 보기`** 안에 있어요.
5. 노래 중에 버튼이 숨으면 화면을 한 번 누르세요. TV 화면을 켜 둔 동안은 폰 화면이 꺼지지 않아요 (배터리를 위해 충전하면서 쓰세요).
6. 블루투스 스피커나 화면 복제로 소리가 늦게 나오면 녹음 전에 `음향 설정` → `더 보기 ›` → 녹음 기본 싱크 → `자동 측정`을 눌러요.

### 휴대폰 리모컨 (옛 길, 같은 와이파이)

기본은 아래 **내 폰 리모컨 (허브)** 이에요. 이것은 `YT 노래방 켜기`로 연 화면에서 같은 와이파이로 쓰는 옛 리모컨이에요 (그대로 돼요).

1. 같은 와이파이에서 TV 대기 화면(또는 `설정` → `더 보기 (고급)` → 옛 폰 리모컨 (같은 와이파이))의 **QR 코드를 휴대폰 카메라로 찍어요.**
2. 리모컨이 열리면 아래에 나오는 안내대로 **크롬 메뉴(⋮) → 홈 화면에 추가**를 눌러요. 다음부터는 홈 화면의 **노래방 리모컨** 아이콘만 누르면 바로 붙어요.
   - 리모컨 주소가 `https`가 아니라서 정식 앱 설치는 안 될 수 있어요. 그래도 아이콘 바로가기는 만들어져요.
   - 안내가 필요 없으면 `닫기`를 눌러요. 다시 안 나와요.
3. **리모컨 코드는 이제 바뀌지 않아요.** 서버를 껐다 켜도 같은 코드라서 QR을 다시 찍을 필요가 없어요. 열어 둔 노래방 화면도 그대로 다시 이어져요. 코드는 이 폴더의 `.remote.json`에 저장돼요 (GitHub에는 안 올라가요).
   - 같은 와이파이의 다른 사람도 이 코드를 계속 쓸 수 있어요. 걱정되면 `설정` → `더 보기 (고급)` → 옛 폰 리모컨 (같은 와이파이) → **새 코드 만들기**를 눌러요. 이미 붙어 있던 휴대폰은 1초쯤 뒤 코드 넣는 화면으로 돌아가고 "코드가 맞지 않아요. PC 화면의 코드를 다시 확인해 주세요"가 나와요 (그 사이에 버튼을 눌렀다면 "코드가 바뀌었어요. 다시 넣어 주세요"). QR을 다시 찍거나 새 코드를 넣어요.
   - 예전처럼 켤 때마다 새 코드를 쓰고 싶으면 같은 곳에서 **켤 때마다 새 코드 만들기**를 켜요.
   - 코드를 너무 많이 틀리면 잠깐 쉬어요: 한 폰이 10번 틀리면 1분, 모든 폰을 합쳐 1분에 20번 틀리면 10분 동안 리모컨이 안 돼요 (붙어 있던 폰도). 10분 뒤 다시 돼요.
4. **PC의 와이파이 주소가 바뀌면 QR을 한 번 더 찍어야 해요.** 공유기가 PC 주소(`192.168.x.x`)를 바꾸면 아이콘이 예전 주소로 가서 연결되지 않아요. 새 QR로 열고 홈 화면 아이콘도 다시 만들어요.

### 내 폰 리모컨 (허브 연결 필요)

내 폰으로 노래방을 조작해요. 휴대폰 리모컨과 같은 화면이지만 와이파이가 달라도 되고, GitHub Pages 주소에서도 돼요.

1. 노래방 화면(PC·TV)에서, 그리고 내 폰의 노래방(GitHub Pages 주소)에서 `설정` → **허브 연결**로 **같은 내 계정**에 로그인해 두어요.
2. 노래방 화면에서 `설정` → `더 보기 (고급)` → **내 폰 리모컨 (허브)** → `폰 리모컨 받기`를 켜요. "켜짐 · 폰 0대"가 나와요.
3. 폰 카메라로 TV 대기 화면의 **내 폰 리모컨 QR**을 찍어요 (GitHub Pages 주소에서 켜 둔 동안 보여요. QR에는 리모컨 주소만 있고 방 이름은 없어요). 또는 폰의 노래방에서 같은 곳의 `이 기기에서 리모컨 열기`를 눌러요 (홈 화면에 추가해 두면 다음부터 바로 열려요). "켜짐 · 폰 1대"가 되면 예약·시작·키·볼륨·녹음·TV 화면을 폰에서 해요. 폰은 4대까지.
4. 폰에 "허브 로그인이 필요해요"가 나오면 폰의 노래방에서 허브에 먼저 로그인해요. "폰 리모컨이 꺼져 있어요"가 나오면 노래방 화면에서 켜요 (켜면 폰이 저절로 다시 붙고, `다시 해 보기`로 바로 붙어요). 노래 중에 폰 화면이 꺼졌다 켜져도 저절로 다시 붙어요.
5. 끄거나 노래방 화면을 닫으면(새로 고침 포함) 끝나요. 켤 때마다 새 방이라 끈 방으로는 못 들어와요. 켜 둔 기기는 다음에 열 때 로그인해 있으면 저절로 다시 켜져요.
- `server.py`로 연 리모컨 주소(`http://192.168.x.x:5173/remote.html`)는 예전처럼 코드 길로 돼요. `YT 노래방 켜기`로 연 화면의 TV 대기 화면은 내 폰 리모컨을 켜도 옛 QR(주소·코드) 그대로예요.
- 내 폰 리모컨이 안 되면: TV QR 밑 글처럼 PC의 `YT 노래방 켜기`로 열어요 → TV에 **옛 폰 리모컨 QR**(같은 와이파이)이 나와요.

### 손님 QR (허브 연결 필요)

같이 있는 사람이 자기 폰으로 곡을 찾아 예약해요. 휴대폰 리모컨과 달리 와이파이가 달라도 되고, 손님은 로그인하지 않아요.

1. 먼저 `설정` → **허브 연결**을 해 두어요 (허브 코드 + 로그인).
2. `설정` → **손님** (설정 창 맨 위) → `손님 초대 QR`을 누르면 방이 열리고 QR이 나와요. TV 대기 화면 오른쪽 아래에도 같은 QR이 나와요 (`TV 화면에 QR 보이기`로 끌 수 있어요). 방이 닫혀 있으면 TV 대기 화면의 `손님 QR 켜기`로도 열어요.
3. 손님은 폰 카메라로 QR을 찍고 이름(8자, 안 넣어도 돼요)을 넣은 뒤 `들어가기`. **곡 찾기** → `예약`, **지금 곡**에서 키 ♭·원래 키·♯(−2~+2, 지금 곡에만), **예약 목록**에서 내 예약 `빼기`.
4. 손님은 6명까지 들어와요. 손님 화면에는 곡 번호·제목·가수와 예약 목록(제목 10개)만 나오고, 내 사용자 이름·좋아요·재생목록·녹음·점수는 안 나와요. 손님 이름은 노래방 예약 목록에만 보여요.
5. 손님이 키를 못 바꾸게 하려면 시트의 `손님이 키 바꾸기`를 꺼요.
6. 다 놀면 `방 닫기` (설정의 손님 칸, 또는 TV 대기 화면의 손님 QR 카드). 손님 화면에 "방이 닫혔어요"가 나오고 손님 이름도 지워져요. 다시 열면 **새 QR(새 방)** 이라 옛 QR로는 못 들어와요. `새 QR 만들기`도 새 방이에요. 노래방 화면을 닫거나 허브 연결을 끊어도 방이 닫혀요. 손님이 2시간 동안 한 명도 없어도 저절로 닫혀요 ("손님이 2시간 동안 없어서 손님 방을 닫았어요").
7. 손님이 예약한 곡이 시작되면 TV에 "OO님 차례예요"가 잠깐 나와요. 손님이 예약한 유튜브 곡이 노래방에서 안 틀어지는 영상이면 건너뛰고, 그 손님 폰에 "OO 곡은 노래방에서 안 틀어져서 넘어갔어요"가 나와요.
8. PC의 `YT 노래방 켜기`(이 PC 주소)로 연 화면에서도 손님 QR은 GitHub Pages(https) 주소로 만들어져요. 손님 폰이 와이파이가 달라도 열려요.
- 유튜브 곡 찾기·예약은 유튜브 곡 기능(CR-030)이 들어간 판에서만 손님 화면에 나와요.

```
npm test
```

가사 읽기, 검색(초성 포함), Google Drive 동기화 합치기 규칙, 파일 이름 → 제목·가수, 가사 후보 정렬·자동으로 넣는 기준, 백업 파일 형식, 리모컨 서버(코드 확인·차단·2MB 넘는 요청·숨김 파일·코드 저장·새 코드), TV로 켜기(크롬 찾기·명령줄, `?tv=1`, 전체 화면 판단), 지연 자동 측정(딸깍 소리 찾기), 숫자판 방향키 이동(옆으로 크게 벗어난 버튼으로는 안 감)을 검사해요. Node.js와 Python이 있으면 따로 설치할 건 없어요.

### 화면 자동 점검 (`npm run test:ui`)

```
npm run test:ui                        전부 (10분 안팎, PC가 바쁘면 더 걸려요)
npm run test:ui -- --out <폴더>         결과·사진 둘 곳 (기본: PC 임시 폴더 %TEMP%\yt-noraebang-ui\날짜-시각)
npm run test:ui -- --only L,M           그 구역만 (곡 목록·곡 추가 점검은 준비로 같이 돌아요)
npm run test:ui -- --shots              스크린샷만
npm run test:ui -- --compare <예전 결과 폴더>   스크린샷을 화소로 비교해 바뀐 사진 목록을 냄
node tests/ui/selftest.mjs              점검이 고장을 정말 잡는지 (일부러 고장 낸 사본으로)
```

- 컴퓨터가 **빈 시험용 Edge**(화면 없이, 소리 끔)로 노래방을 켜고, 버튼·단축키·창·TV 화면·휴대폰 리모컨을 실제로 눌러 본 뒤 기능 목록 번호마다 결과표(`results.md`·`results.json`)와 스크린샷 55장 (유튜브 점검 사진 4장 · 재생목록 점검 사진 3장 따로)(`shots/`, PC 1280×800 · TV 1920×1080 · 폰 412×915 · 폰 가로 915×412)과 기기 맞추기 점검 사진 5장(`cr039-*`)을 남겨요. 결과는 통과 / 실패 / 알려진 문제 / 건너뜀(이유) / 일부 통과·사람 확인 / 기기 확인 필요 / 기존 테스트 / 사람 확인으로 나뉘어요. 실패가 하나라도 있으면 끝 코드가 1이에요.
- **내 곡·녹음·휴대폰 리모컨 코드는 건드리지 않아요**: 매번 새 빈 Edge 프로필, 5173이 아닌 빈 포트, 리모컨 코드 파일은 임시 폴더(`.remote.json`은 읽지도 쓰지도 않음). Google 로그인·Drive 요청은 막고, 가사 서버(LRCLIB)는 가짜 답을 줘요. 끝나면 Edge·서버·임시 폴더를 지우고 저장소 `git status`와 `.remote.json`이 그대로인지 확인해요.
- Windows + Edge + Node 22 이상(내장 WebSocket) + Python이면 돼요. 새로 설치할 것은 없어요. 글꼴과 QR 라이브러리만 인터넷에서 받아요 (안 되면 그 줄은 "건너뜀").
- `npm test`와 따로예요. 화면을 고친 뒤와 검수 때 둘 다 돌려요. 사진은 공개 저장소에 올리지 않아요 (저장소 안에는 `tests/ui/out/`만 둘 수 있고 git에서 빠져요).
- 유튜브 곡(V 구역)은 **진짜 유튜브에 닿지 않아요**: IFrame API는 가짜 플레이어(`tests/ui/fake-yt.js`, 재생목록도 가짜 목록), 검색·재생목록 읽기(Data API)는 가짜 답, 썸네일은 회색 그림, 검색 열쇠도 가짜 글자예요.
- 기능 목록 번호와 자동 점검의 연결표는 `tests/ui/features.json`이에요. **기능을 더하거나 바꾸면 이 파일도 같이 고쳐요** (번호마다 분류 auto/test/partial/human/device와 조건).

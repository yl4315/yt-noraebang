# YT 노래방

**바로 열기: https://yl4315.github.io/yt-noraebang/**

집에서 쓰는 노래방 웹앱이에요. MR을 넣고 가사에 맞춰 부르고, 녹음하고, 점수를 받고, TV 화면에 띄워서 예약까지 할 수 있어요.

## 켜기

1. **`YT 노래방 켜기.bat`** 을 더블클릭해요. 검은 창이 뜨고 브라우저가 열려요.
2. 검은 창을 닫으면 꺼져요.
3. 처음 켤 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러요. 휴대폰 리모컨에 필요해요.

**TV로 바로 노래하려면 `YT 노래방 TV로 켜기.bat`** 을 더블클릭해요. 크롬이 주소창 없는 창으로 열리고, 바로 TV 화면(대기 화면)이 나와요.

- 크롬이 꺼져 있었으면 처음부터 전체 화면으로 열려요. 크롬이 이미 켜져 있었으면 창으로 열릴 수 있어요. 그때는 화면에 나오는 안내대로 **아무 키나 한 번 누르면**(또는 `F`) 전체 화면이 돼요.
- 곡과 녹음은 평소 쓰던 크롬 안에 있어서 그대로 보여요. 크롬이 없으면 기본 브라우저로 열려요.
- 노래방이 이미 켜져 있으면 서버를 또 켜지 않고 TV 화면만 열어요. `T`를 누르면 TV 화면에서 나가서 관리 화면이 돼요.

직접 켤 때는 이렇게 해요.

```
python server.py            # 이 PC에서만
python server.py --lan      # 같은 와이파이의 휴대폰 리모컨도 허용
python server.py --open     # 켜면서 브라우저 열기
python server.py --tv       # 켜면서 크롬을 TV 화면·전체 화면으로 열기
```

마이크는 https 주소(위의 **바로 열기** 주소)나 이 PC의 `http://localhost:5173` 에서 돼요. 브라우저가 그 밖의 주소(예: 같은 와이파이 주소 `http://192.168…`)에서는 마이크를 막아서, 서버로 켤 때는 노래방 화면을 이 PC에서 여세요. 주소 끝에 `?tv=1`을 붙이면(예: `http://localhost:5173/?tv=1`) 열자마자 TV 화면이 돼요.

| 기능 | 어디서 |

| 가사 싱크 직접 맞추기 | `가사 싱크 편집` (Space로 찍기, ⌫ 되돌리기, 1~4 배속) |
| 가사 전체 당기기·미루기 | `가사 타이밍` ±0.1초 / ±1초, `[` `]` |
| 키 바꾸기 | `키 ♭/♯` 또는 `,` `.` (사용자별로 곡마다 기억해요) |
| 녹음 · 녹음 후 싱크 조절 | ● 버튼, 내 녹음 → `싱크·믹스 조절`, WAV 저장 |
| TV 화면 · 예약 | `TV 화면` 또는 `T`. 번호 + Enter 예약, `P` 우선예약, `S` 검색(초성 가능), `L` 예약 목록, `C` 인기차트, `M` 내 목록, `J` 간주점프, Esc 취소 |
| 사용자 · 좋아요 · 재생목록 | 위쪽 사용자 버튼(`U`), 곡의 ♡ / ＋, `내 목록` 탭 |
| 휴대폰 리모컨 | TV 대기 화면의 QR 코드를 휴대폰으로 찍기 (같은 와이파이) |
| Google Drive 동기화 · 녹음 백업 | `설정` → Google Drive 곡 창고 |
| 인터넷 없이 부르기 | 기기에 저장된 곡은 오프라인에서도 돼요. `설정` → 저장 공간 |
| 백업 파일 | `설정` → 백업 파일 만들기 / 불러오기 (`.ytbackup`) |

## 데이터는 어디에 저장되나요?

- 곡, 가사, 녹음은 **이 브라우저 안 저장소(IndexedDB)** 에 있어요. 이 폴더에는 없어요.
- 다른 브라우저나 기기에서는 보이지 않아요. Drive에 연결하거나 백업 파일로 옮기세요.
- 이 저장소(GitHub)에는 코드와 데모곡만 올라가요. MR, 가사, 녹음은 올라가지 않아요.

## Google Drive 연결

클라이언트 ID는 앱에 들어 있어요(`js/cloud.js`의 `DEFAULT_CLIENT_ID`, Google Cloud 프로젝트 `yt-noraebang`). `설정` → **Google 계정 연결**만 누르면 돼요.

- 로그인할 수 있는 계정은 Google Cloud의 **테스트 사용자**에 넣은 계정뿐이에요. 가족 계정을 쓰려면 그 주소도 테스트 사용자에 넣으세요.
- Drive의 **'YT 노래방' 폴더에 MR 파일을 직접 넣어도** 다음 동기화 때 곡 목록에 들어와요. 파일 이름에서 제목·가수를 자동으로 뽑아요.
- 클라이언트 ID의 **승인된 JavaScript 원본**에는 `http://localhost:5173`과 `https://yl4315.github.io`가 들어 있어야 해요. 다른 주소에서 열면 로그인이 막혀요.

## 휴대폰에서 쓰기

**https://yl4315.github.io/yt-noraebang/** 를 휴대폰 크롬이나 사파리에서 열고, **홈 화면에 추가**하면 앱처럼 설치돼요.

- 휴대폰 리모컨은 이 PC의 `YT 노래방 켜기`(또는 `TV로 켜기`)로 연 화면에서만 돼요. GitHub Pages 주소에서는 안 돼요.

### 휴대폰 리모컨

1. 같은 와이파이에서 TV 대기 화면(또는 `설정` → 휴대폰 리모컨)의 **QR 코드를 휴대폰 카메라로 찍어요.**
2. 리모컨이 열리면 아래에 나오는 안내대로 **크롬 메뉴(⋮) → 홈 화면에 추가**를 눌러요. 다음부터는 홈 화면의 **노래방 리모컨** 아이콘만 누르면 바로 붙어요.
   - 리모컨 주소가 `https`가 아니라서 정식 앱 설치는 안 될 수 있어요. 그래도 아이콘 바로가기는 만들어져요.
   - 안내가 필요 없으면 `닫기`를 눌러요. 다시 안 나와요.
3. **리모컨 코드는 이제 바뀌지 않아요.** 서버를 껐다 켜도 같은 코드라서 QR을 다시 찍을 필요가 없어요. 코드는 이 폴더의 `.remote.json`에 저장돼요 (GitHub에는 안 올라가요).
   - 같은 와이파이의 다른 사람도 이 코드를 계속 쓸 수 있어요. 걱정되면 `설정` → 휴대폰 리모컨 → **새 코드 만들기**를 눌러요. 이미 붙어 있던 휴대폰은 "코드가 바뀌었어요"가 나오니 QR을 다시 찍어요.
   - 예전처럼 켤 때마다 새 코드를 쓰고 싶으면 같은 곳에서 **켤 때마다 새 코드 만들기**를 켜요.
4. **PC의 와이파이 주소가 바뀌면 QR을 한 번 더 찍어야 해요.** 공유기가 PC 주소(`192.168.x.x`)를 바꾸면 아이콘이 예전 주소로 가서 연결되지 않아요. 새 QR로 열고 홈 화면 아이콘도 다시 만들어요.
